|---|---|---|---|
| **[AI 1]** 저장 기능이 없습니다. 파일을 다시 열면 모든 영화가 미분류로 돌아갑니다. | 직접 파일을 껐다 켜보니 작성했던 내용이 다 지워지고 처음 상태로 돌아갔습니다. | 반영 | 실제로 해 보니 그렇고, 기획서의 완성 기준 약속에 맞기 때문입니다. |
| **[AI 2]** ‘처음으로’가 직접 추가한 영화를 지우지 않습니다. | 직접 눌러보니 새로 추가했던 영화까지 모두 지워지고 처음 상태로 깨끗하게 돌아갔습니다. | 보류 | 직접 해 본 결과 사실과 다르고, 기획서의 원래 목적에 맞기 때문입니다. |
| **[AI 3]** 빈 제목을 막지 않아 기획서를 어깁니다. 빈 상태로 추가하면 빈 카드가 생깁니다. | 제목을 아무것도 안 쓰고 ‘추가’를 눌렀더니 이름 없는 빈 카드가 덜렁 생겼습니다. | 반영 | 직접 해 보니 그렇고, 올바른 입력 조건이라는 목적에 맞기 때문입니다. |
| **[동료 1]** 휴대폰으로 열어 보니까 좀 불편했어요. | 스마트폰으로 볼 때 어떤 점이 구체적으로 불편했는지 글만으로는 알기 어렵습니다. | 되묻기 | 스마트폰으로 보실 때 구체적으로 어떤 화면이나 조작이 어떻게 불편하셨나요? |
| **[동료 2]** 카드 옮기는 게 처음엔 좀 헷갈렸어요. | 처음 사용할 때 카드를 어떻게 움직여야 하는지 조작법이 한눈에 들어오지 않을 수 있습니다. | 보류 | 주관적인 첫인상에 가깝고, 꼭 필수로 고쳐야 할 이유는 아니기 때문입니다. |
| **[동료 3]** 카드를 끌어서 옮기는 게 불편했어요. S칸까지 끌고 가려면 화면을 올려야 해요. | 아래쪽에 있는 영화를 맨 위 S칸까지 드래그해서 올리려니 거리가 멀어서 번거로웠습니다. | 반영 | 직접 해 보니 그렇고, 화면 조작을 편하게 개선한다는 목적에 맞기 때문입니다. |
| **[동료 4]** 카드 색이 좀 칙칙한 느낌? | 카드의 전반적인 색감이 회색빛과 베이지톤으로 차분하게 들어가 있습니다. | 보류 | 개인적인 취향의 영역이라 꼭 바꿀 이유가 없기 때문입니다. |
| **[동료 5]** 영화 포스터 사진이 같이 나오면 훨씬 보기 좋을 것 같아요. | 현재 화면에는 글자만 적힌 심플한 카드 형태로 만들어져 있습니다. | 보류 | 기획서의 기본 범위를 넘어서는 추가 제안이자 취향에 가깝기 때문입니다. |
| **[동료 6]** C칸은 굳이 없어도 될 것 같아요. | 기획서에 애초에 S·A·B·C 네 칸으로 나누어 정리하겠다고 정해져 있습니다. | 보류 | 기획서의 기본 조건 및 목적과 정면으로 부딪히기 때문입니다. |
