# 실행 및 검증 로그 — 산책 서기

## 1. 작업 분할 단위 및 분할 기준
검증과 기록의 추적성을 높이기 위해 작업을 **단계 단위**와 **검증 시나리오 단위**로 나누었다.
- **단계 단위:** `설계(v1/v2)` → `11턴 멀티턴 대화 검증` → `환각 검증(Q1~Q6)` → `미해결 이슈 정리`
- **검증 시나리오 단위:** 단일 입력, 모호한 입력 되묻기, 동일 입력 반복 일관성, 중간 조건 변경(개체명 매핑), 환각 유도 질의(`Q1~Q6`), 추가 기록 입력 및 누적 합산
- **분할 기준:** 한 번에 여러 변경과 질문을 섞으면 어느 지점에서 오류가 발생했는지 판별하기 어렵기 때문에, **실패 원인 분리와 재검증 용이성**을 기준으로 세분화했다.
