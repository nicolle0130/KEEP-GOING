# 모델 비교 분석서 — 산책 서기

## 1. 비교 대상 모델 (3종 이상)
1. **Gemini (무료 티어 — 메인 채택 모델):** 일상 구어체 메모 이해력과 규칙·예시 추종력이 균형 잡혀 있으며 비용 부담 없이 반복 검증과 운영이 가능하다.
2. **chatGPT(무료/저비용 대안):** 짧은 지시에는 빠르게 반응하나 다견 상태가 섞이거나 되묻기 조건이 겹칠 때 누락 항목을 `미기재` 대신 생략하는 경향이 일부 관찰된다.
3. **COPILOT(무료/저비용 대안):** 문맥 유지력과 세부 규칙 준수도가 부족하고 개인 산책 일지 정리 과업 대비 만족도가 낮음.

## 3. 기준별 점수 산출 근거
- **사실 무결성 (환각 억제):** 메모에 없는 기온이나 `기관지 협착증 3기` 같은 의학적 진단명 유도 질문에 대해 지어내지 않고 부재 사실을 정확히 답변하는지 평가했다. Gemini는 `미기재` 및 원문 사실 기반 답변을 안정적으로 유지했으며, 경량 모델 A는 일부 턴에서 추정 표현이 섞일 여지가 있었고, 고추론 모델 B는 정확도가 가장 높았다.
- **출력 구조·되묻기 일관성:** 정보가 부족할 때 3가지 항목을 되묻고, 충분할 때 `기본 활동`·`개체별 컨디션`·`특이사항` 3단 구조를 지키는 정도를 보았다. Gemini와 chatGPT는 Few-shot 3종을 바탕으로 형식을 안정적으로 따랐다.
- **멀티턴 문맥·조건 변경 유지:** 10턴 이상 대화에서 개체 명칭(`첫째·둘째` → `장군·송군`) 변경과 날짜별 산책 시간 합산(45분 + 45분 = 90분)을 놓치지 않는지 평가했다.
- **비용 효율 및 무료 운영 적합성:** 무료 요금제 제약 아래 추가 과금 없이 반복 테스트와 일일 기록 정리를 지속할 수 있는지를 기준으로 삼았다. Gemini가 비용 제약 조건에서 가장 현실적인 선택이다.

## 4. 최종 모델 선정 및 운영 결론
- **최종 선정:** **Gemini (무료 티어)**를 메인 모델로 선정한다.
- **운영 보완:** 무료 모델 특성상 긴 멀티턴 대화나 규칙 변경 시 문맥이 흔들릴 수 있으므로, `system-design.md`에 정의한 **입력 템플릿 고정**, **상태 요약 블록 재고정**, **Q1~Q6 검증 체크리스트 통과 후 반영** 절차를 함께 적용한다.
