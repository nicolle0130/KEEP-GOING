## 수정 기록

### 수정 기록 1
- 발견한 문제: 견종 목록이 소형·중형·대형과 믹스 3종까지 26개뿐이라 말티푸, 사모예드, 삽살개, 대형견(그레이트 데인 등) 같은 흔한 견종이 없었습니다.
- AI에게 전달한 요청: "견종대상의 폭을 좀 넓혀주고…"
- 수정 후 테스트 결과: 견종이 104종(순수 견종 99종, 믹스 5종)으로 늘었고, 초대형 그룹이 생겼으며, 그룹 안이 가나다순으로 정렬되어 나옴. 선택지 106개 확인 (테스트 1). 표준 체중 수치는 일반적인 성견 기준 대략값이라 출처 확인은 아직 하지 않음.
- 수정 이유: 선택 폭을 넓혀 목록에 없다는 이유로 '직접 입력'을 쓰는 경우를 줄이기 위해서입니다. 크기 그룹은 체중 중간값으로 자동 분류하게 해서 맞춤 산책 시간 계산과 목록 분류가 같은 기준을 쓰게 했고, 기존 견종 ID는 그대로 두어 저장된 기록이 유지되게 했습니다.

### 수정 기록 2
- 발견한 문제: 나이를 년/개월로 입력하는 기능은 기존 파일에 이미 있었습니다. 다만 입력한 나이가 어떻게 해석되는지 바로 확인하기 어려웠고, 잘못된 값이 들어간 상태에서 반려견 탭을 바꾸면 입력칸에 이상한 값이 들어갈 수 있는 부분이 코드에서 발견되었습니다.
- AI에게 전달한 요청: "견종 나이를 year/month로 입력해줘"
- 수정 후 테스트 결과: 입력한 나이 아래에 "2년 6개월 (총 30개월)"처럼 표시되도록 코드를 추가했고, 이상한 값은 빈칸으로 처리하도록 고침. 페이지 로딩과 문법 검사는 통과함. 잘못된 값 상태에서 탭을 바꾸는 상황은 따로 테스트하지 않음.
- 수정 이유: 요청한 기능이 이미 있어서 새로 만들지 않고, 확인 문구와 오류 처리만 보강하는 편이 기존 동작을 덜 바꾸기 때문입니다.

### 수정 기록 3
- 발견한 문제: 기획서에서 GPS 경로 추적을 비목표로 두어, 산책 시간을 직접 입력해야 했고 거리는 기록할 수 없었습니다.
- AI에게 전달한 요청: "혹시 gps 기능 탑제할수 있을까?"
- 수정 후 테스트 결과: 'GPS 산책 측정' 카드(시작, 일시정지, 끝내기, 경로 선 표시, 강도 자동 선택, 기록 저장)가 추가되고 기록표에 거리 열이 생김. 가상 위치값 시뮬레이션에서 거리 226m, 7분 30초, 1.4kcal로 예상과 일치(테스트 2). 몸무게가 비었을 때와 권한 거부 때의 안내도 동작함(테스트 3). 실제 스마트폰 측정은 미실시.
- 수정 이유: 걸은 거리를 자동으로 재면 직접 입력하는 번거로움과 오차가 줄어듭니다. 좌표는 저장하지 않고 거리·시간·칼로리만 기록해 개인정보 부담을 줄였고, 지도 서비스는 쓰지 않아 파일 하나로 열리는 조건을 지켰습니다. 기획서의 한계 및 비목표도 이에 맞춰 고쳤습니다.
